# 연금플러스 4일 실행계획

## 목표

기능1 이관 현황판과 기능2 인출순서 시뮬레이터를 구현하고 Vercel에 배포한다.

## 일정

| 날짜 | 목표 | 주요 작업 | 완료 기준 |
|---|---|---|---|
| 8월 31일 | 개발 시작 | 범위·역할 확정, 공통 프로젝트 설정, 각자 기능 개발 시작 | 프로젝트 실행 및 담당 화면 작업 시작 |
| 9월 1일 | 개별 기능 구현 | 기능1·기능2·공통 계산 병렬 개발 | 각자 담당 기능의 핵심 동작 완료 |
| 9월 2일 오전 | 개별 작업 마무리 | 자체 테스트, 빌드 확인, 통합 준비 | 통합 가능한 코드와 확인 방법 준비 |

| 9월 3일 | 최종 제출 | QA, Production 배포, SRS·GitHub·발표자료 정리 | 제출 링크 3개 준비 |

## 개발 규칙

- 각자 자신의 브랜치와 담당 폴더에서 작업한다.
- 다른 사람 담당 파일은 수정 전에 공유한다.
- 새로운 패키지를 설치하기 전에 팀에 알린다.
- 9월 2일 14시 이후에는 신규 기능을 추가하지 않는다.
- 기능 완료 후 `npm run build`를 확인한다.
