# 연금플러스 MVP PRD

> 상태: MVP 범위 확정
> 목적: 기존 상세 PRD에서 3명·4일 MVP에 필요한 범위만 선별합니다.

## 1. 제품 개요

연금플러스는 연금계좌 이전 과정의 진행 단계와 매매 제한을 보여주고, 연금 인출 시 적용되는 순서와 예상 세액을 모의계산으로 설명하는 모바일 웹 MVP입니다.

## 2. 해결하려는 문제

사용자는 연금계좌 이전을 신청한 뒤 현재 처리 단계와 매매 제한 기간을 알기 어렵습니다. 또한 연금을 인출할 때 어떤 재원부터 차감되고 세금과 실수령액이 어떻게 달라지는지 미리 이해하기 어렵습니다.

## 3. MVP 범위

### 확정 범위

- 핵심 사용자: PB의 도움 없이 연금계좌 이전 과정을 직접 확인해야 하는 일반 고객
- 핵심 흐름: 연동된 연금계좌 선택 → 보유 종목 확인 → 이전 시 제한 사항 확인 → 이관 조건 최종 확인 → 단계별 진행 현황 확인
- 보조 흐름: 인출 조건 입력 → 법정 차감 순서·예상 세금·실수령액 확인
- 구현 화면: 홈, 이전 계좌·종목 확인, 이전 전 확인, 이관 현황판, 인출 조건 입력, 인출 결과
- 중요 예외: 고객 확인 필요, 인출금액이 평가금액을 초과한 경우
- 데이터: 실제 마이데이터 연동 상황을 가정한 로컬 시연용 데이터
- 담당: 공통·통합 양승연 / 기능1·2 담당자는 팀 카카오톡 확인

## 4. 제외 범위

- 로그인·회원가입·본인 인증
- 실제 마이데이터·금융기관·예탁결제원 API 연동
- 서버·데이터베이스와 실사용자 데이터 저장
- 실제 이체·출금·주문
- 타명의·상속 상세 흐름

## 5. 성공 기준

- 핵심 사용자가 시작부터 목표 달성까지 중단 없이 이동할 수 있습니다.
- 핵심 흐름을 2분 이내에 시연할 수 있습니다.
- 모바일 360px와 데스크톱에서 핵심 레이아웃이 깨지지 않습니다.
- 모든 시연 화면은 `시연용 데이터`, 계산 결과는 `모의계산`임을 표시합니다.
- 구현 기능이 SRS Requirement, GitHub Issue, 검증 결과와 연결됩니다.
