# 연금플러스 MVP SRS Lite

> 상태: MVP 범위 확정, Requirement 12개 작성 완료 · Issue 연결 예정
> 원본: [상세 SRS v1.0](SRS_연금플러스_v1.0.md)

## 1. 목적과 범위

이 문서는 3명·4일 안에 구현할 연금플러스 MVP의 기능·UI·비기능 요구사항과 검증 조건을 정의합니다. 상세 제품 전체 범위가 아니라 실제 데모에 포함할 요구사항만 관리합니다.

## 2. 사용자와 핵심 흐름

- 핵심 사용자: PB의 도움 없이 연금계좌 이전 과정을 직접 확인해야 하는 일반 고객
- 핵심 Happy Path: 연동된 연금계좌 선택 → 보유 종목 확인 → 이전 시 제한 사항 확인 → 이관 조건 최종 확인 → 단계별 진행 현황 확인
- 보조 흐름: 인출 조건 입력 → 법정 차감 순서·예상 세금·실수령액 확인
- 중요 예외: 고객 확인 필요 / 인출금액이 평가금액을 초과한 경우

## 3. 요구사항 작성 형식

| 항목 | 작성 내용 |
|---|---|
| ID | `FR-001`, `UI-001`, `NFR-001` 형식 |
| Requirement | 사용자가 확인하거나 수행할 수 있어야 하는 것 |
| Rationale | 이 요구사항이 필요한 이유 |
| Input / Rule / Output | 입력, 적용 규칙, 출력 |
| Acceptance Criteria | 통과·실패를 판정할 수 있는 조건 |
| Source | PRD 또는 Knowledge Base 근거 |
| Priority | Must / Should / Could |

## 5. UI·비기능 요구사항

- 모바일 360px을 우선합니다.
- 시연용 데이터와 모의계산임을 명시합니다.
- 완료일은 단일 날짜가 아니라 기간으로 표시합니다.
- 확정 정보와 추정 정보를 시각적으로 구분합니다.
- 실제 이체·출금이 실행되는 것으로 오해할 표현을 사용하지 않습니다.
- 계산식은 UI 컴포넌트와 분리하고 대표값을 테스트합니다.
