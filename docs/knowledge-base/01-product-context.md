# 제품 맥락

## 배경

연금계좌 이관 처리 속도는 원 사업자와 공통 인프라의 영향을 받으므로 수관사가 단독으로 크게 줄이기 어렵습니다. 사용자에게 필요한 것은 근거 없는 빠른 완료 약속이 아니라 현재 단계, 다음 단계, 제한되는 업무와 예상 기간을 이해할 수 있는 정보입니다.

## 핵심 문제

사용자는 현재 처리 단계와 매매 제한 기간을 알기 어렵습니다.

## 제품 방향

- 기능1: 이관 단계·예상 완료 기간·매매 제한을 보여줍니다.
- 기능2: 법정 인출순서·예상 세금·실수령액을 모의계산으로 보여줍니다.
- 실제 금융 기능이 아니라 사용자 가설 검증용 MVP로 구현합니다.
