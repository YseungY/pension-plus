# 리서치 근거

## 현재 확인된 근거

| 근거 | 제품에 미친 영향 | 상태 |
|---|---|---|
| 기존 화면은 처리 상태를 한 줄로 표시 | 기능1에서 단계별 현황과 다음 행동을 함께 표시 | 상세 PRD 근거 |
| 이관 중 매매 제한 안내가 부족 | 제한 업무와 해제 예상 기간을 핵심 정보로 선정 | 상세 PRD 근거 |
| 인출 재원은 법정 순서에 따라 차감 | 기능2를 자유 추천이 아닌 결정론적 모의계산으로 설계 | 상세 PRD·법령 근거 |
| 실제 API·민감정보 처리는 4일 MVP에 과도함 | 실제 연동 상황을 가정한 로컬 시연용 데이터 사용 | MVP 결정 초안 |

## 추가 확인이 필요한 항목

- 세법과 세율 기준일의 최종 검증
- 실제 상품별 이관 소요기간과 잠금 정책
- 마이데이터에서 확보 가능한 필드와 미제공 필드
