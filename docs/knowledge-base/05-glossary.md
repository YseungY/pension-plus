# 용어집

| 용어 | 뜻 | 화면 표현 원칙 |
|---|---|---|
| 이관사 | 연금계좌를 보내는 기존 금융회사 | 사용자가 아는 회사명과 함께 표시 |
| 수관사 | 연금계좌를 받는 금융회사 | 이번 기획에서는 KB증권 관점 |
| 실물이전 | 보유 상품을 매도하지 않고 다른 연금계좌로 옮기는 방식 | 가능 여부를 종목별로 표시 |
| 현금화 | 이전 전에 상품을 매도·해지해 현금으로 바꾸는 과정 | 예상 손익과 소요기간을 함께 표시 |
| 완료일 밴드 | 완료 가능성을 단일 날짜가 아닌 기간으로 안내한 값 | 확정일처럼 단정하지 않음 |
| 매매 제한 기간 | 이관 처리 중 일부 거래가 제한되는 구간 | 제한 업무와 예상 해제 시점을 함께 표시 |
| 인출순서 | 연금계좌에서 재원이 차감되는 법정 순서 | 사용자의 추천 선택처럼 표현하지 않음 |
| 시연용 데이터 | 실제 연동 상황을 가정해 만든 로컬 데이터 | 모든 mock 화면에 명시 |
| 모의계산 | 입력값과 기준에 따른 예상 결과 | 실제 세액과 다를 수 있음을 안내 |
