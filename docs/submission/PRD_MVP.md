# 연금플러스 MVP PRD

> **이 문서는 MVP Lite 버전입니다.** 전체 12화면·66개 요구사항의 원본은 [`team/product/PRD_원본상세.md`](../team/product/PRD_원본상세.md)(상세 PRD v2.1)를 참고하세요. 실제 4일간 구현하는 범위는 이 문서 기준입니다.

> 상태: MVP 범위 확정
> 목적: 기존 상세 PRD에서 3명·4일 MVP에 필요한 범위만 선별합니다.

## 1. 제품 개요

연금플러스는 연금계좌 이전 과정의 진행 단계와 매매 제한을 보여주고, 연금저축 계좌의 연금 외 수령(중도인출) 시 적용되는 순서와 예상 세액을 모의계산으로 설명하는 모바일 웹 MVP입니다.

## 2. 해결하려는 문제

사용자는 연금계좌 이전을 신청한 뒤 현재 처리 단계와 매매 제한 기간을 알기 어렵습니다. 또한 연금저축을 해지하지 않고 일부만 인출(연금 외 수령)할 때 어떤 재원부터 차감되고 세금과 실수령액이 어떻게 달라지는지 미리 이해하기 어렵습니다.

## 3. MVP 범위

### 확정 범위

- 핵심 사용자: PB의 도움 없이 연금계좌 이전 과정을 직접 확인해야 하는 일반 고객
- 핵심 흐름: 타사 퇴직연금 가져오기 → 보유 종목 확인 → 이전 시 제한 사항 확인 → 이관 조건 최종 확인 → 단계별 진행 현황 확인(홈의 "이관사 확인 진행 중" 카드에서 진입)
- 보조 흐름: 연금저축 관리 진입(공통 구현 완료) → 출금 관리에서 연금 외 수령 선택 → 연금 외 수령(중도인출) 조건 확인 → 법정 차감 순서·예상 세금·실수령액 확인
- 구현 화면: 홈, 이전 계좌·종목 확인, 이전 전 확인, 이관 현황판, 연금저축 관리(공통 구현 완료), 연금 외 수령 조건 확인, 연금 외 수령 결과
- 중요 예외: 고객 확인 필요, 인출금액이 평가금액을 초과한 경우
- 데이터: 실제 마이데이터 연동 상황을 가정한 로컬 시연용 데이터
- 담당: 공통·통합 양승연 / 기능1·2 담당자는 팀 카카오톡 확인

## 4. 제외 범위

- 로그인·회원가입·본인 인증
- 실제 마이데이터·금융기관·예탁결제원 API 연동
- 서버·데이터베이스와 실사용자 데이터 저장
- 실제 이체·출금·주문
- 타명의·상속 상세 흐름
- 연금저축 관리 화면 내 입금 관리, 연금수령(기존 수령), 연금저축 해지 — 화면 목록에는 표시하되 실제 동작은 구현하지 않음(핵심 범위는 연금 외 수령)

## 5. 성공 기준

- 핵심 사용자가 시작부터 목표 달성까지 중단 없이 이동할 수 있습니다.
- 핵심 흐름을 2분 이내에 시연할 수 있습니다.
- 모바일 360px와 데스크톱에서 핵심 레이아웃이 깨지지 않습니다.
- 모든 시연 화면은 `시연용 데이터`, 계산 결과는 `모의계산`임을 표시합니다.
- 구현 기능이 SRS Requirement, GitHub Issue, 검증 결과와 연결됩니다.
