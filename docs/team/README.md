## 폴더 구조

```text
team/
├─ start/          # 개발 전 결정과 일정
├─ product/        # 상세 PRD와 예상 프로토타입
├─ development/    # 설치·실행·Git 협업
├─ design/         # 디자인 가이드와 원본
└─ workflow/       # 팀 인수인계·Goal·발표자료 초안
```

최종 제출 문서는 상위 `docs/` 폴더에 있습니다.
