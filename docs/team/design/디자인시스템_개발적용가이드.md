# 연금플러스 디자인 시스템 개발 적용 가이드

| 항목 | 내용 |
|---|---|
| 시각 원본 (1순위) | `docs/team/design/design-system/연금플러스 모바일 앱.dc.html` — 스플래시부터 인출 세금 시뮬레이터까지 실제 화면 목업 9종. 화면 만들 때 제일 먼저 열어본다. |
| 시각 원본 (보조) | `연금플러스 디자인 시스템.dc.html` — 색상·타이포 등 토큰 정의 원본 |
| 실행 엔진 | `docs/team/design/design-system/support.js` — 두 dc.html 파일이 브라우저에서 열릴 때 불러오는 렌더링 스크립트. 디자인 콘텐츠가 아니라 자동 생성된 실행 파일이므로 읽거나 참고할 필요는 없지만, dc.html과 **같은 폴더에서 분리·삭제하면 두 파일이 안 열리니 이동하지 않는다.** |
| 목적 | 팀원과 코딩 에이전트가 같은 규칙으로 React 화면을 구현하기 위한 기준 |

> 원본 HTML은 시각 참고용이다. 인라인 스타일을 화면 코드에 그대로 복사하지 않고 아래 토큰과 공통 컴포넌트로 구현한다.

---

## 1. 핵심 방향

- 전문적이지만 투명한 금융 서비스
- Deep Navy를 구조와 주요 행동에 사용
- Mint는 진행·완료·유리한 금액에만 사용
- Pretendard 단일 서체
- 모바일 393px 우선(아이폰 17 기준)
- 날짜·금액·제한 이유를 구체적으로 표시

- 흰 배경의 작은 민트 텍스트는 `mint-600` 대신 `mint-700`을 사용한다.
- `text-tertiary`는 핵심 본문이나 작은 필수 정보에 사용하지 않는다.
- 상태는 색만으로 구분하지 않고 라벨·아이콘·설명을 함께 표시한다.

## 4. 타이포그래피와 레이아웃

- 화면 제목: 28~32px, 700
- 섹션 제목: 24px, 700
- 카드 제목: 18~20px, 700
- 기본 본문: 15~16px
- 보조 설명: 13~14px
- 주요 금액: 24~28px, `tabular-nums`
- 모바일 좌우 여백: 20px
- 카드 내부 여백: 20px
- 주요 섹션 간격: 24~32px
- 일반 버튼 최소 높이: 48px
- 핵심 CTA 높이: 56px
- 카드 radius: 16~20px
- 버튼 radius: 12~14px

MVP에서는 다크 모드를 구현하지 않는다.

## 5. 먼저 만들 공통 컴포넌트

| 컴포넌트 | 용도 |
|---|---|
| `PageHeader` | 뒤로가기와 화면 제목 |
| `Button` | primary, accent, outline, text, disabled |
| `Card` | 기본, 강조, 경고 카드 |
| `StatusBadge` | 완료, 진행, 대기, 주의, 불가 |
| `Money` | 원 단위·천 단위 쉼표·고정폭 숫자 |
| `ProgressBar` | 진행률과 텍스트 라벨 |
| `Notice` | 정보, 주의, 오류 안내 |
| `BottomSheet` | 계산 근거와 상세 설명 |

기존 공통 컴포넌트가 있으면 화면 안에 같은 모양을 다시 만들지 않는다.

## 6. 금융 화면 규칙

### 연금 이전

- 현재 단계는 `진행 중` 파란색으로 표시한다.
- 완료 단계와 최종 완료는 민트로 표시한다.
- 통제 밖 구간은 회색 `대기`로 표시한다.
- 완료일은 단정하지 않고 기간 또는 `예상` 라벨을 사용한다.

### 인출순서

- 과세제외금액 → 이연퇴직소득 → 세액공제분·운용수익 순서를 고정한다.
- 현재 차감 재원만 옅은 민트 배경으로 강조한다.
- 순서 번호를 항상 표시한다.
- 금액은 비율보다 원 단위를 우선한다.
- 결과 가까이에 `모의계산`과 기준일을 표시한다.

---

## 7. 문장 규칙

- 날짜를 먼저 말하고 제약을 설명한다.
- 불가능한 이유 다음에 사용자가 할 수 있는 행동을 쓴다.
- `예상`, `영업일`, 기준일을 명시한다.
- 내부 용어 `이수관`보다 화면에서는 `연금 이전`을 사용한다.
- `수 영업일`, 오류 코드 단독 표시, 수익 단정 표현은 사용하지 않는다.
- 안내 문구는 두 문장, 약 45자 이내를 우선한다.

## 8. 팀 전달과 에이전트 사용

팀원은 파일을 개별 전송받아 복사하기보다 GitHub에서 같은 저장소를 clone한다. 다음 파일이 함께 있어야 한다.

```text
AGENTS.md
docs/team/start/간단_실행계획.md
docs/team/development/개발환경_협업가이드.md
docs/team/design/디자인시스템_개발적용가이드.md
docs/team/design/design-system/연금플러스 디자인 시스템.dc.html
docs/team/design/design-system/support.js
```

코딩 에이전트에는 `AGENTS.md`와 세 개의 Markdown 문서를 먼저 읽게 한다. 원본 디자인 HTML은 시각 예시를 확인할 때 참고한다.
